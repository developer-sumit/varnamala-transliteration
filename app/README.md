# 📱 Varnamala Android App (`app`)

The core Android application module for **Varnamala**, built entirely with **Jetpack Compose**, **Material 3**, **CameraX**, and **Coroutines / Flow**.

---

## 🎯 Architecture

The app follows standard Android architectural best practices with Unidirectional Data Flow (UDF) and MVVM:

```
app/src/main/java/com/sumit/varnamala/
├── MainActivity.kt               # Navigation host, permission checks, system bars
├── VarnamalaApp.kt               # Application subclass initializing signboards & singletons
├── data/
│   ├── history/                  # Scan history & saved favorites persistence
│   ├── ocr/                      # OCR data models (OCRResult, TextBlock, TextLine)
│   └── preferences/              # Preferences DataStore (SettingsManager)
├── ocr/
│   ├── PaddleOCRHelper.kt        # High-level wrapper connecting ppocr-sdk to Compose
│   └── PaddleModelProvisioner.kt # Manages Tiny, Small, and Medium model tiers
├── tts/
│   ├── TTSManager.kt             # Text-to-speech engine wrapper
│   └── RasaTTSHelper.kt          # Offline neural TTS integration
├── ui/
│   ├── components/               # Reusable Jetpack Compose components
│   │   ├── OCROverlayCanvas.kt   # Bounding box & live text overlay renderer
│   │   └── LockGate.kt           # Optional biometric authentication guard
│   ├── screens/                  # Feature screens
│   │   ├── CameraScreen.kt       # CameraX live scanning & continuous OCR
│   │   ├── GalleryScreen.kt      # Device image picker & gallery viewer
│   │   ├── ImageDetailScreen.kt  # Pinch-to-zoom image viewer with 1:1 OCR overlays
│   │   ├── TextInputScreen.kt    # Manual typing transliteration
│   │   ├── HistoryScreen.kt      # Scan history & starred items
│   │   ├── ModelManagerScreen.kt # OCR model downloads & storage manager
│   │   ├── ResourceSetupScreen.kt# Initial onboarding & asset unpacking
│   │   └── SettingsScreen.kt     # Font sizing, theme, security & preferences
│   └── theme/                    # Material 3 colors, typography, shapes
└── utils/
    ├── Transliterator.kt         # Bridge to :transliteration KMP engine & Aksharamukha
    └── BitmapUtils.kt            # Image rotations, EXIF handling, and cropping
```

## 📸 Key Features & Technical Details

### 1. Camera Scanning (`CameraScreen.kt`)
- Direct integration with **CameraX** (`ImageAnalysis` & `PreviewView`).
- Continuous non-blocking image analysis pipeline: processes frames in background coroutines without freezing camera preview.
- Dynamic bounding box projection with `OCROverlayCanvas`.
- Supports torch/flash toggle, tap-to-focus, and single-shot capture.

### 2. Gallery & Image Detail (`ImageDetailScreen.kt`)
- Full pinch-to-zoom and pan via Compose `graphicsLayer` and `pointerInput`.
- 1:1 mapped OCR bounding boxes scaled accurately to the displayed image aspect ratio.
- Automatic EXIF orientation normalization so bounding coordinates match unrotated bitmaps.
- Interactive word-level and line-level selection with tap-to-copy and text-to-speech.

### 3. Transliteration & Script Support (`utils/Transliterator.kt`)
- Calls into the pure Kotlin multiplatform `:transliteration` engine.
- Supports Aksharamukha script conversion across 12+ Indic scripts and international Romanization schemes.

### 4. Privacy & Security (`LockGate.kt`)
- Optional Biometric Authentication (Fingerprint / Face Unlock / Device Credential) using `BiometricPrompt`.
- Disabled by default; securely guards history and private scans when enabled in Settings.

## 🏗️ Build & Signing Configurations

The app supports building completely out-of-the-box without proprietary signing keys:
- **Debug builds**: Use standard Android debug keystores automatically generated by Gradle.
- **Release builds**: Safe fallback to unsigned / debug signing when `key.properties` is absent.
- To produce signed release builds, copy `key.properties.template` to `key.properties` and provide your release keystore parameters.
