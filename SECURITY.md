---

## Reporting a Vulnerability

We prioritize the privacy and security of our users. Because Varnamala executes all OCR and transliteration workloads 100% locally on-device without cloud transmission, user data remains strictly private.

If you discover a security flaw, permission leakage, or potential vulnerability:

1. Please do not publish the vulnerability in public GitHub issues.
2. Reach out to the maintainers with technical details, steps to reproduce, and any affected configurations.
3. We will review reports promptly and publish patches in subsequent releases.
